## CatValidatorNullablePropertyRuleBuilderExtensions Class

The comparison and range rules for nullable value types, like `decimal?`, `int?` and `DateTime?`\.
They work like the rules in [CatValidatorPropertyRuleBuilderExtensions](CatValidatorPropertyRuleBuilderExtensions.md 'Cat\.Validators\.Extensions\.CatValidatorPropertyRuleBuilderExtensions'), with one difference:
a `null` property passes\. Add `NotNull` to the property when a value is required\.
When you compare with another property or take a bound from the model, a `null` there passes too\.
