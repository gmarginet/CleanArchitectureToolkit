# `Clean Architecture Toolkit for .NET`  

This NuGet package is part of the Clean Architecture Toolkit (CAT).

CAT is a clean, modular architecture foundation for .NET applications. It embraces SOLID principles and focuses on maintainability, testability, and scalability through clear boundaries and pluggable design.  

For detailed information on the toolkit NuGet packages, take a look at the [CAT GitHub repo](https://github.com/gmarginet/CleanArchitectureToolkit).
