# Excalidraw SVG drawings

Drawings live in `resources/schemas/*.excalidraw.svg`: `CatArchitecture`, `CatServiceProjectStructure` and `CatDemoArchitecture`. One file per drawing. The SVG holds the visible picture plus the Excalidraw scene between `<!-- payload-start -->` and `<!-- payload-end -->`.

## Where to work
- Keep every temporary file in the session scratchpad directory from the system prompt. That means generator scripts, decoded JSON, screenshots and logs. Never use `C:\gma` or other folders.
- The helper script for the payload is [excalidraw-payload.ps1](excalidraw-payload.ps1), next to this file. Run it from there. Only your own generator scripts go in the scratchpad.
- Run scripts with the Bash tool: `powershell.exe -NoProfile -ExecutionPolicy Bypass -File <scratchpad path>\script.ps1`.
- Use the real scratchpad path (`C:\Users\GertMarginet\AppData\Local\Temp\claude\...\scratchpad`). The `GERTMA~1` short form resolves inconsistently.
- If tool output is lost, redirect to a file in the scratchpad and read it with the Read tool. Wrap scripts in try/catch that writes the error to a scratchpad file.
- In PowerShell, write `($b.Length - 2)` with parentheses and spaces inside argument lists. Otherwise it parses as an array operation and fails silently.
- Set the culture to Invariant when generating numbers on this machine.
- Clean up the scratchpad leftovers when you are done.

## Payload format
- The payload is the base64 (of Latin-1 bytes) of this JSON: `{"version":"1","encoding":"bstring","compressed":true,"encoded":"<zlib bytes as Latin-1 chars>"}`.
- To decode, skip the 2 byte zlib header and inflate with DeflateStream.
- To encode, add the header `78 9C` and an Adler-32 trailer.
- [excalidraw-payload.ps1](excalidraw-payload.ps1) does both. Use `-Mode Decode` to read a scene and `-Mode Encode` to write one back.

## House style
- Rounded rectangles (roundness type 3).
- Blue `#a5d8ff` for projects and services.
- Green `#b2f2bb` for databases.
- Dotted `#1971c2` frames for groups.
- Dotted boxes for optional or later parts.
- Excalifont (`fontFamily` 5), size 20, roughness 1, strokeWidth 2.
- The SVG root has `filter="invert(93%) hue-rotate(180deg)"`.
- Reuse the `<defs>` font block from an existing SVG in `resources/schemas`.
- A picture generated by script is clean, not hand-drawn. Re-exporting from Excalidraw with "Embed scene" gives the rough look. Mention this to the owner when it matters.

## Steps
1. Read an existing drawing that is close to what is asked. Decode its scene to see the structure and coordinates.
2. Write a generator script in the scratchpad that builds both the scene JSON and the visible SVG elements from one list of shapes, so the picture and the scene match.
3. Write the SVG file with the `<defs>` font block, the picture, and the payload markers.
4. Encode the scene into the payload with the helper script.
5. Render a preview with headless Chrome: `chrome.exe --headless --screenshot=<scratchpad>\preview.png file:///<path to svg>`. View the PNG with the Read tool and fix overlaps and cut-off text.
6. Check the result by decoding the payload again. It should match the scene JSON you wrote.
7. Reference the drawing from the readme or plan that needs it, and clean up the scratchpad.
